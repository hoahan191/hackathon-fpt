# 30-second judge talk

“We built a group restaurant picker that turns multiple personal rankings into one fair decision. Each person ranks their favorites, the app weights top picks more heavily, and it explains the winning result in plain language. We used AI to accelerate the implementation and polish the terminal experience, but the real correctness is enforced by tests for tie-breaking, duplicate protection, and winner scoring. The result is fast, transparent, and easy to demo in a live judging environment.”
